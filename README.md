Hydra

Hydra is a free macro for the Roblox game Fisch. It is made to automate fishing and make grinding easier.

The macro is intended for people who want to fish without having to do everything manually.

Information

* Game: Fisch (Roblox)
* Type: Fishing macro
* Price: Free
* Platform: Windows
